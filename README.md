# Firdaus Ravi Faizzani — Portfolio

A responsive personal portfolio built with Next.js, TypeScript, Tailwind CSS, and shadcn/ui conventions.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Validation

```bash
npm run lint
npm run build
```
